## Review priorities

### Must fix
- Protect scrollable content from the fixed bottom navigation across long screens.
- Protect tracker/task/reminder editor content from the fixed Save dock.
- Ensure destructive actions and final fields can always scroll fully above the Save dock.
- Fix malformed reminder history microcopy: “הצג את כל ההושלמו”.

### High priority
- Home: reduce the vertical footprint of the empty “פעיל עכשיו” state.
- Home: prevent the floating add button from obscuring actionable content while scrolling.
- Trackers: distinguish clearly between an action available to mark complete and an already-completed state.
- Verify Android Back flows across detail → edit → save, overlays, tabs and direct notification routes.

### Medium priority
- Tracker history: replace ambiguous “טופל” wording with a factual status.
- Tasks: review hierarchy between “ערוך” and “סמן משימה כהושלמה”.
- Reminders: verify recurring-reminder start-date wording is unambiguous.
- Settings: review whether all notification test controls belong in the main user-facing settings area.
- Backup: shorten explanatory copy where possible without removing critical recovery information.

### Future / scalability
- Consider collapsing completed tracker actions/stages in long editor forms.
- Consider revealing reminder fields only after the user chooses to add a reminder to a task.
- Consolidate accumulated runtime override layers into a cleaner module structure after product behavior stabilizes.
- Align file names, internal module versions and documented versions.
